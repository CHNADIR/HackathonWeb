# BlueAcces

BlueAcces est un MVP React/Vite d'application de guidage inclusif pour le campus de l'Universite Paris 8 Vincennes-Saint-Denis.

## Fonctionnalites

- Carte interactive Leaflet avec points d'interet du campus.
- Calcul d'itineraire accessible entre deux lieux.
- Adaptation selon profil moteur, visuel, auditif ou cognitif.
- Signalement d'obstacles temporaires pris en compte dans les parcours.
- Profil utilisateur avec contraste eleve, grande taille de texte et trajets favoris.
- Module evenementiel temporaire pour jeu de piste QR codes.
- API Express de demonstration pour lieux et obstacles.

## Commandes

```bash
npm install
npm run dev
npm run api
npm run build
npm run lint
```
